# M12 visual review surface

This directory is an isolated browser prototype requested for visual review.
It is not the M12 Rust/TS scene contract, semantic evaluator or native/WASM
package loader. Keep that distinction visible in the UI and evidence.

Use fixture data and a shared data-driven graphic interpreter. Do not add
domain-specific rendering dispatch or modify qualified core runtime contracts.
The fixture binding IDs are illustrative; do not present them as parsed SysML
source ranges. Run the real browser test after changes.
